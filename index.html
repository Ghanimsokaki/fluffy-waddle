Settings

OpenRouter and NVIDIA use one browser-supplied AI key at a time. CodeCraft, Moduck and Bytez use server keys for confirmed accounts. Puter uses a separate Puter sign-in. Connector credentials stay in this browser, unencrypted.

AI provider key

Switching AI providers clears this key. Connectors may require their own separate credentials.

Puter uses its own account and usage limits or charges. Its sign-in is separate from Gemby and persists when you sign out here. Puter chat does not currently support MCP tools, connector proposals or web search in this app.

Web search

OpenRouter may charge for searches, even with free models. The model decides when to search. This search option is available only with OpenRouter.

box by Simular MCP

Connects to Simular's cloud computer via the app server. Get a personal key at box.simular.ai/access. Tool results are sent to the AI provider. Every tool call requires approval.

Other MCP servers

Add an HTTPS Streamable HTTP MCP link or paste an mcpServers JSON configuration. Remote servers must allow browser CORS. Local commands, OAuth login and legacy SSE endpoints are not supported.

Tokens are visible in the JSON editor and stored unencrypted in this browser. Connect only trusted servers; tool definitions and results go to your AI provider, and each tool call requires approval.

Skills

Enable and edit these reusable instruction skills. Enabled instructions are sent with each message. This does not run skill scripts or install skill packages.

First-time Supabase setup

1. Create a Supabase project and open its SQL Editor. Run the database setup SQL.

2. Enable email authentication and add your website URL to Supabase's allowed redirects.

3. In Vercel → Project → Settings → Environment Variables, add SUPABASE_URL and SUPABASE_ANON_KEY (the publishable/anon key). Redeploy.

Never use the service-role or secret key here, and never share credentials in chat.

Puter uses a separate account and may open a sign-in popup. It can stay signed in even if Gemby sign-in fails. Puter usage may incur charges. After GitHub sign-in, connect Puter in Settings.
