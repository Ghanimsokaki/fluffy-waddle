Set up in a minute

You only need an API key for the provider you use.

Get a free key at openrouter.ai/keys and, for NIM, at build.nvidia.com.
Run node server.js in the project folder and open http://localhost:8080.
Open Settings, paste your keys, choose a model and chat.
