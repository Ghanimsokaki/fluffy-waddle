Settings

OpenRouter and NVIDIA use one browser-supplied AI key at a time. CodeCraft uses the server key for approved accounts. Keys and connector tokens stay in this browser, unencrypted, and are removed when you sign out.

AI provider key

Switching AI providers clears this key. Connectors may require their own separate credentials.

Web search

Toggle search for a single chat with the 🌐 button next to the message box. Search results are treated as untrusted data.

box by Simular MCP

Connects to Simular's cloud computer via the app server. Get a personal key at box.simular.ai/access. Tool results are sent to the AI provider. Every tool call requires approval.

Other MCP servers

Add an HTTPS Streamable HTTP MCP link or paste an mcpServers JSON configuration. Remote servers must allow browser CORS. Local commands, OAuth login and legacy SSE endpoints are not supported. Names and links sync to your account; tokens stay on this device.

Tokens are visible in the JSON editor and stored unencrypted in this browser. Connect only trusted servers; tool definitions and results go to your AI provider, and each tool call requires approval.

Skills

Enable and edit these reusable instruction skills. Enabled instructions are sent with each message. This does not run skill scripts or install skill packages.

First-time Supabase setup

1. Create a Supabase project and open its SQL Editor. Run the database setup SQL.

2. Enable email authentication and add your website URL to Supabase's allowed redirects.

3. In Vercel → Project → Settings → Environment Variables, add SUPABASE_URL and SUPABASE_ANON_KEY (the publishable/anon key). Redeploy.

Never use the service-role or secret key here, and never share credentials in chat.
