Set up in a minute

You only need an API key for the provider you use.

Get a free key at openrouter.ai/keys and, for NIM, at build.nvidia.com.
Run node server.js in the project folder and open http://localhost:8080.
Open Settings, paste your keys, choose a model and chat.

OpenRouter

NVIDIA NIM

NVIDIA blocks direct browser requests (no CORS). The default /api/nvidia works when you run node server.js. Using a Cloudflare Worker? Paste its URL ending in /v1.

Web search

OpenRouter may charge for searches, even with free models. The model decides when to search. Not available with NVIDIA.

box by Simular MCP

Connects to Simular's cloud computer via the app server. Get a personal key at box.simular.ai/access. Leave blank to use a configured server token. Tool results are sent to the AI provider. Every tool call requires approval.

Other MCP servers

Add an HTTPS Streamable HTTP MCP link or paste an mcpServers JSON configuration. Remote servers must allow browser CORS. Local commands, OAuth login and legacy SSE endpoints are not supported.

Tokens are visible in the JSON editor and stored unencrypted in this browser. Connect only trusted servers; tool definitions and results go to your AI provider, and each tool call requires approval.
